v1.5.2 2026-10-24

  • 경험치 던전 비교 기준을 해당 층만 반복 탐험하는 조건으로 수정했습니다.
  • 기준 모험가 레벨과 레벨별 경험치 계산에 해당 층의 기본 레벨을 사용하며, 다른 층의 레벨은 반영하지 않습니다.

v1.5.1 2026-10-24

  • 경험치 페이지의 모험가 레벨·출발 층 입력을 없애고 돈 수급처럼 층별 자동 계산과 추천 1~5위를 표시합니다.
  • 1층 출발·각 층 평균 레벨과 같은 모험가를 비교 기준으로 사용하며, 추천의 모험가 레벨별 값과 전체 던전 층별 표를 펼쳐볼 수 있습니다.
  • 이전에 저장한 경험치 전용 입력값이 자동 계산에 영향을 주지 않도록 정리했습니다.

v1.5.0 2026-10-24

  • 경험치 던전 1~5위와 던전별 추천 층을 첫 화면·수급 메뉴·모바일 바로가기에 추가했습니다.
  • 모험가 레벨과 출발 층을 입력하면 출발~추천 층의 정수 평균 레벨로 귀환 기본 경험치를 계산합니다.
  • 총 획득 경험치와 귀환 기본분을 구분하고, 보너스·배율·상한·경로 근사의 적용 범위를 표시합니다.
  • 기존 시간 보정에서 골드 획득 메시지를 대리변수로 사용한 점과 상자 사건별 검증 한계를 명확히 안내합니다.

v1.4.2 2026-10-23

  • 반복 골드·몬스터 드롭 계산에서 단회·클리어 후보를 추첨 전에 제거해 반복 보상 확률이 커지던 문제를 수정했습니다.
  • 첫 몬스터 편성과 추가 호출의 후보 조건을 분리하고, 반복형 클리어 전투는 보상에서 제외하되 소요 시간에 포함합니다.
  • 단회·시간 복구형 대상이 비활성인 반복 수급 가정과 경로·시간 계산의 근사 범위를 안내합니다.

v1.4.1 2026-10-22

  • UI 개편 후 흩어져 있던 길드 안내·길드 던전·이벤트 준비를 독립된 길드 분류로 모았습니다.
  • 길드 가입·운영, 상점·공헌도, 재료 교환, 시설 확장과 이벤트 보상으로 가는 탐색 경로를 정리했습니다.

v1.4.0 2026-10-22

  • 전체 화면을 새로운 색상·타이포그래피·카드 구성으로 개편했습니다.
  • 재료 채집과 돈 수급 던전을 첫 화면과 고정 바로가기에 배치했습니다.
  • 관련 정보를 모험과 던전·왕국과 육성·장비와 아이템·전투 도감으로 묶고 분류→목록→상세 탐색을 제공합니다.
  • 왕국·탐험 범위 설정을 접어서 정리하고 현재 위치와 뒤로 가기 탐색을 추가했습니다.

v1.3.0 2026-10-22

  • 실제 모험 기록을 대조해 이동 간격·방 방문 비중·추가 지연 시간을 보정했습니다.
  • 골드 계산에서 채집 행동과 시간, 아이템 판매액을 제외하고 서로 다른 던전 1~5위와 수급처별 금액을 표시합니다.
  • 식량에 따른 탐험 시간 한도와 보정 검증 범위를 계산 조건에 추가했습니다.

v1.2.0 2026-10-22

  • 건물을 기본 건물 32종과 직업 건물 19종으로 나누었습니다.
  • 건물 780개 성장 단계의 해금 내용·필요 왕국 레벨·골드·재료와 선행 시설 조건을 추가했습니다.
  • 길드 안내에도 레벨별 건설·확장 비용과 해금 내용을 함께 표시합니다.
  • 왕국 성장 페이지에서 도달 층 설정을 열 때 발생하던 오류를 수정했습니다.
