# 경험치 던전 계산 범위

이 페이지는 캐릭터 1명당 **귀환 기본 경험치**의 비교다. 총 획득 경험치 또는 완전한 게임 시뮬레이션이 아니다.

## 자동 계산과 평균 층 레벨

별도 모험가 레벨·출발 층 입력 없이 모든 후보를 1층 출발로 계산한다. 왕국·탐색 단계·선택 지도·제외 던전·최대 도달 층과 시간 조건은 돈 수급 페이지와 공유한다. 1층~해당 층까지 `floor.level`을 정수 평균한 값을 그 층의 기준 모험가 레벨로 쓴다. 따라서 순위는 동레벨(D=0) 귀환 기본분의 비교이며 모든 모험가에게 공통인 순위는 아니다. 층별 체류 시간으로 평균을 가중하지 않는다.

추천 1~5위는 서로 다른 던전의 최고 층을 고른다. 같은 후보 전체를 던전별·층별로 펼쳐볼 수 있으며 각 추천에는 모험가 레벨 구간별 예상 경험치를 표시한다. 이전에 저장한 `adventureLevel`, `experienceStartFloor`는 설정 복원에서 무시해 자동 계산에 영향을 주지 않는다. 게임 14.4.6의 `AdventureParty.AdventureLevelAvg` 및 `Character.ReturnCastle` 검토에 따른다.

R은 목표 층 일반 반복 전투의 몬스터 실제 레벨(기본+편성 추가) × 10 누적 기대량, T는 목표 층 시간의 기본 10초 틱이다. D는 평균 층 레벨−모험가 레벨이다.

| D | 전투 기본분 | 시간 기본분 |
|---|---|---|
| 2 이상 | 2R | trunc(T/2) |
| 1 | trunc(R) | trunc(T/4) |
| 0 | trunc(R/2) | trunc(T/8) |
| −1 | trunc(R/4) | trunc(T/16) |
| −2 | trunc(R/6) | trunc(T/32) |
| −3 | trunc(R/8) | trunc(T/64) |
| −4 이하 | 0 | 0 |

각 부분을 절삭한 뒤 합산한다. 확률적 누적 보상의 기대량에 절삭을 적용하므로 실제 개별 시행의 절삭 평균과 차이가 날 수 있다. 평균 레벨을 목표 층 자체 레벨로 대체하지 않는다.

## 포함하지 않는 것

직업 행동·상자 발견·함정·클리어 경험치, 전역 배율, 캐릭터의 남은 경험치 상한, 생존·이탈 상태는 합산하지 않는다. 원본 기록의 총 경험치와 귀환 기본분 차이를 맞추기 위한 임의 배율은 사용하지 않았다. 1층~목표 층의 평균 레벨은 적용하지만 중간 층과 귀환 중 전투·시간 경험치는 더하지 않는다. 목표 층 밖 소요 시간은 별도 입력으로 예산에서 차감한다.

전투 횟수와 목표 층 체류 시간은 보정된 갱신 근사다. 기존 v1.4.2의 전체 후보 경쟁·첫/추가 호출 분리를 유지한다. 반복형 클리어 전투는 소요 시간에만 넣고 보상은 제외한다. 골드 페이지의 도적의 숲 제외 정책은 경험치에 적용하지 않는다.

## 시간 검증의 해석

기존 시간 계수는 관측 전투 완료 건수와 골드 획득 메시지(kind35)를 입력한 조건부 적합 결과다. 모든 상자의 개봉 시간을 직접 측정한 계수가 아니므로 기본값은 근사로 표시하고 사용자 조정을 유지한다. 경험치의 총 지급 예측 정확도나 전체 모험 수익 정확도로 바꾸어 해석하지 않는다.

## 확인

`node scripts/check-experience-model.cjs`, `node scripts/check-yield-model.cjs`, `node tests/frontend-smoke.cjs`로 분기·정수 절삭, 출발~도달 층 평균, 설정 보존, 필터·순위·화면 연결 및 기존 수급 기능을 검사한다. 개인 기록·추출 자료·게임 바이너리는 공개하지 않는다.
